# Alquidar

##  Descripción

Alquidar es un sistema web de gestión de alquileres que busca centralizar y organizar la información relacionada con propiedades, propietarios, inquilinos, contratos, pagos y vencimientos.

El proyecto surge con el objetivo de facilitar la gestión de los alquileres y mejorar el seguimiento de la información entre propietarios e inquilinos.

##  Estado del proyecto

Actualmente el proyecto se encuentra en etapa de desarrollo.

Durante el TP1 se realizó la estructura inicial del sitio utilizando HTML5 y HTML semántico.

Durante el TP2 se trabajará en la transformación de esta estructura en una interfaz web completa mediante CSS, aplicando Flexbox, CSS Grid, variables CSS y Responsive Design.

##  Variables CSS

Las variables CSS se definirán utilizando `:root` y se reutilizarán mediante `var()`.

Se utilizarán principalmente para centralizar:

* Colores.
* Espaciados.
* Bordes.
* Sombras.

Esto permite mantener una identidad visual coherente y facilita la modificación de los estilos del proyecto.

##  Flexbox

Se utilizará Flexbox principalmente en la sección de navegación y encabezado del sitio.

Su objetivo será facilitar la distribución, alineación y organización de los elementos.

> Esta sección se completará con los detalles de la implementación durante el desarrollo del TP2.

##  CSS Grid

Se utilizará CSS Grid para organizar determinadas secciones del sitio, especialmente aquellas que presenten elementos distribuidos en filas y columnas.

> Esta sección se completará con los detalles de la implementación durante el desarrollo del TP2.

##  Responsive Design

El proyecto deberá adaptarse correctamente a diferentes tamaños de pantalla:

*  Celulares.
*  Tablets.
*  Computadoras.

Para esto se utilizarán Media Queries y unidades relativas cuando sea necesario.

> Esta sección se completará durante el desarrollo del TP2.

##  Estrategias SEO

Como parte del proyecto se implementarán diferentes estrategias de SEO.

Entre ellas:

1. Uso de un `<title>` descriptivo.
2. Implementación de `meta description`.
3. Utilización de HTML semántico.
4. Uso de atributos `alt` descriptivos en imágenes.
5. Implementación de enlaces internos descriptivos.

También se trabajará en una correcta jerarquía de encabezados mediante `h1`, `h2` y `h3`.

##  Objetivo del proyecto

El objetivo de Alquidar es desarrollar progresivamente una aplicación web que permita gestionar información relacionada con alquileres, facilitando el seguimiento de propiedades, contratos, pagos y vencimientos.
